🎵 Metrônomo Eletrônico

Marcador de tempo musical com chip 555

Chip 555 Potenciômetro Buzzer Projeto final

// sobre o projeto

O que você vai construir

Um metrônomo é um relógio que marca o tempo musical. Músicos usam para manter o ritmo constante durante os ensaios. Os metrônomos antigos eram mecânicos (com um pêndulo), mas hoje são totalmente eletrônicos.

Nesse projeto você vai usar o chip timer 555 — o mesmo das práticas — junto com um potenciômetro para controlar a velocidade. O resultado é um "bip bip bip" rítmico que você pode acelerar ou desacelerar girando a haste.

Diferente dos metrônomos mecânicos (que podem variar com a posição), o metrônomo eletrônico é sempre preciso: o tempo medido é exatamente o mesmo, independente de qualquer fator externo.

Esse circuito junta vários componentes ao mesmo tempo: chip 555, potenciômetro, buzzer, 2 capacitores, 4 resistores e 2 LEDs.

⚡ Desafio sem passo a passo

Esse é o projeto mais complexo do kit. O esquemático parece assustador, mas se você montou o chip 555 nas práticas, você consegue esse. Dica estratégica: monte primeiro todos os componentes sem fios, confira as posições, depois faça as conexões com os fios.

// materiais necessários

O que você vai precisar

Chip Timer 555
4 Resistores pequenos
2 Capacitores
Potenciômetro
2 LEDs (qualquer cor)
Buzzer
Fios jumper
Suporte de pilhas com pilhas
Placa de ensaios
⚠️

Atenção às polaridades: capacitores (faixa branca = negativo), LEDs (perna longa = positivo), chip (bolinha = pino 1, lado esquerdo), buzzer (sinal + = positivo).

💡

Ao girar o potenciômetro, a velocidade dos LEDs piscando muda — e o mesmo acontece com a frequência dos bips do buzzer. Esse é o ajuste de BPM do seu metrônomo.

🎵

BPM médio para músicas pop: 120. Experimente encontrar essa velocidade girando o potenciômetro — você vai ouvir quando chegar no ritmo certo!

✓ Resultado esperado

Com tudo conectado, os 2 LEDs devem piscar alternadamente no mesmo ritmo que o buzzer faz bip. Girando o potenciômetro, você acelera ou desacelera o ritmo. Você acabou de construir um instrumento musical eletrônico!

Se não funcionou:

  • Confira a polaridade de todos os componentes (transistores, LEDs, capacitores)
  • Verifique as conexões com fio — um fio mal encaixado é a causa mais comum
  • Use o esquemático para conferir cada ligação pino por pino
  • Se estiver travado, volte para as práticas individuais dos componentes usados
